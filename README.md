Cache-segar adalah data tersimpan yang umurnya masih di bawah batas TTL (misal < 30 menit) sehingga langsung ditampilkan tanpa memanggil internet. Cache-basi adalah data cadangan lama yang ditampilkan ketika perangkat offline dan jaringan gagal diakses. First-run offline terjadi saat aplikasi dibuka tanpa internet dan belum ada sama sekali data yang pernah disimpan. Label status data sangat penting agar pengguna mengetahui tingkat keakuratan informasi cuaca yang mereka lihat di layar.
